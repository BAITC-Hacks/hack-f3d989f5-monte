# Beeline Tariff Marketing Campaigns — агент

## Запуск

```powershell
python -m pip install -r requirements.txt
python local_eval.py
python local_eval.py --runs 10
python make_submission.py
```

Для сдачи нужны `agent.py`, сгенерированный `submission.csv` и `requirements.txt`.
Агент использует выданный участникам `data/change_tariff.csv`, если файл доступен.
Если файла нет или он не читается, гипотезы для пилотов строятся из аудитории и
параметров тарифов, доступных через `env`.

## Подход

Агент группирует целевую аудиторию по текущему тарифу и ARPU сегменту. Из
истории смен тарифов он оценивает величину изменения ARPU и частоту каждого
перехода. Это априорная оценка для отбора гипотез, а не знание скрытых эффектов
судейской среды.

Для 17 наиболее перспективных переходов запускаются пилоты по 200 абонентов.
В пяти самых ценных исходных сегментах используется SMS, когда хватает бюджета;
остальные пилоты идут через бесплатный push. Результат SMS приводится к масштабу
push перед объединением с исторической оценкой. Гипотезы распределяются между
разными исходными сегментами;
повторять много пилотов на одной группе невыгодно из-за общего лимита охвата.
Наблюдение пилота объединяется с априорной оценкой с весом, зависящим от числа
контактов и известного шума пилота. Для финального плана используется слегка
консервативная оценка эффекта.

На каждый сегмент выбирается один целевой тариф. Канал подбирается по ожидаемому
приросту за вычетом стоимости контактов; бюджет и охват проверяются при
составлении плана. Push пилоты бесплатны по бюджету, но расходуют охват и
учитываются оценщиком как реальные кампании.

## Локальная проверка

На мок модели `python local_eval.py --runs 20`: 20 из 20 прогонов в плюс,
минимум 3 799 841, медиана 4 508 165, максимум 4 649 014 у.е. На тех же seed
вариант только с push пилотами имел медиану 4 507 719 и стандартное отклонение
345 249; смешанные пилоты с выбранной дисперсией приора 0.08² — медиану
4 508 165 и стандартное отклонение около 256 тыс. Эти цифры проверяют
механику и устойчивость к шуму; в финале модель эффектов другая.

Замер `Measure-Command { python -X utf8 local_eval.py }` на текущем компьютере:
1,71 секунды на один полный прогон, включая пилоты и оценку. Это значительно
меньше лимита в 10 минут; вызовов LLM в агенте нет.
