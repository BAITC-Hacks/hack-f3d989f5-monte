# Beeline Tariff Marketing Campaigns

Агент выбирает аудиторию, целевой тариф и канал контакта. Для сдачи нужны
`agent.py`, сгенерированный `submission.csv` и `requirements.txt`.

## Запуск

```powershell
python -m pip install -r requirements.txt
python local_eval.py --runs 20
python make_submission.py
```

## Подход

История из `data/change_tariff.csv` задаёт предварительную оценку переходов.
Это другая аудитория, поэтому агент допускает заметную ошибку переноса истории
и обновляет оценку пилотами по байесовской формуле. Если история недоступна,
гипотезы строятся по профилю аудитории и справочнику тарифов из `env`.

До 17 пилотов по 200 клиентов используют push и SMS. SMS применяется к пяти
наиболее ценным исходным ячейкам; в обычном отборе это до 10 SMS пилотов и
8000 у.е. Остальные пилоты бесплатны по бюджету, но также расходуют контакты.
Перед масштабированием из оценки вычитается одно апостериорное стандартное
отклонение. Каждый пилот и внешний метод агента защищены от исключений.

Похожие ячейки с одним ARPU сегментом и целевым тарифом объединяются через
`filter_current_tariff="tariff_A;tariff_B"`. Слабейшая оценка группы должна
составлять не менее 90% сильнейшей; группа ограничена 5000 абонентами. Эффекты
ячеек суммируются с учётом их размера и ARPU.

Финальный план содержит до 10 кампаний. Первичный выбор канала резервирует
бюджет для следующих групп; затем агент проверяет выгодные повышения канала
на оставшийся бюджет. Лимиты учитывают пилоты и финал. Это эвристическая
стратегия распределения ресурсов, а не глобальная оптимизация.

## Проверка устойчивости

```powershell
python -B -X utf8 stress_eval.py --runs 20 --sensitivity
```

Тест временно подменяет модель одновременно для пилотов и оценщика в памяти
процесса. Проверяются смещение эффектов вниз, инверсия четверти переходов,
неоднородные эффекты и конверсия, повышенный шум пилотов. Файлы среды не
изменяются; агент не получает таблицу эффектов.

Значения констант выбраны по явным статистическим и экономическим допущениям
до стресс-прогонов. Обоснования, сравнение со старой версией, чувствительность
и ограничения проверки находятся в [STRESS_RESULTS.md](STRESS_RESULTS.md).

На обычной мок-модели: медиана чистого прироста **4 470 837**, минимум
**3 719 372** у.е., **20 из 20** прогонов положительные. Медиана на 2,8% ниже
предыдущей настройки. На каждом из четырёх стресс-сценариев новая версия также
дала 20 положительных результатов; это не гарантия для скрытой судейской модели.

Во всех проверках лимиты соблюдены без обрезания кампаний оценщиком.
`requirements.txt` совпадает с `pip freeze`: `numpy==2.5.3`, `pandas==3.0.6`.
Замер `Measure-Command { python local_eval.py }`: **1,22 секунды** на полный
прогон при лимите 10 минут. Вызовов LLM в агенте нет.
